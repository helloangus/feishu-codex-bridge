# ADR 0002：过渡期设置变更要求全局空闲

状态：P3 阶段实施，后续可由入队设置快照替代。

Python 允许任务运行时修改模型和 Plan 设置。Rust 当前在异步准备任务时读取持久化设置，因此先采用调度器已有的全局空闲变更门控：存在执行、排队、待保存或另一项变更时拒绝修改；查询不受此限制。该差异防止已接收任务在等待期间改变模型或执行模式，并避免异步保存完成次序覆盖命令顺序。

设置按用户和目录保存，字段更新在同一 JsonStore 锁内合并，`/new` 不清除设置。模型设置先向 backend 获取有效列表并验证，再持久化；`default` 是恢复后端默认模型的命令参数。变更沿用耐久认领和最近 1,000 条去重窗口，认领后失败或崩溃不自动重试。

完整命令迁移时，可在消息接收序列中加入设置版本和任务快照，使运行中修改仅影响之后接收的任务；补充乱序保存和重启测试后再放宽门控。当前 Plan 仅接通执行模式和最终计划文本，计划确认、实施按钮和完整问答不在本次交付范围。
