# ADR 0003：过渡期目录切换要求全局空闲

状态：P3 阶段实施。

Python 的目录变更以当前用户的任务状态为主要门控。Rust 首版沿用会话和设置的全局变更门控：执行、排队、接收状态保存或其他变更尚未完成时拒绝 `/cd <路径>`；`/cd` 查询仍可使用。这样目录持久化和运行时目录映射按同一顺序生效，新任务不会在保存期间读到旧目录并延迟执行。

目录按用户保存；会话、模型和 Plan 继续按用户/目录隔离。只有耐久保存成功后才更新运行时目录映射。任务在接收时固定目录快照，启动前重新验证其仍为工作区内的同一规范路径；turn 请求显式传递该目录和对应的可写范围。删除或重定向后的快照会被拒绝，用户可用工作区内绝对路径重新选择，不静默回退到初始目录。

命令使用最近 1,000 条持久化消息去重，不自动重试已认领的失败请求。缺失目录通过 `/cd-confirm <编号>` 单独确认，绑定用户、聊天、原目录和 10 分钟有效期；最多保留 100 项，忙时拒绝不消费确认，切换成功、新提示、超时和重启会使旧确认失效。

确认先耐久认领，再重新核对原始路径与目标；从根目录描述符逐级打开/创建，不跟随被替换的符号链接。目录和 JSON 保存无法形成跨资源原子事务，保存失败时保留已创建目录，报告失败且不更新当前选择，不自动回删或重试。目录确认卡片按钮已复用该流程，卡片原位刷新仍待完善；按钮操作编号一次性消费，忙时可继续用原文字确认编号重试。真实飞书验收按用户安排延后。
